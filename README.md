# Sway Dotfiles (ThinkPad T495)

Мои конфиги для оконного менеджера Sway (Arch Linux / Debian).

## Установка на новую систему
1. `git clone git@github.com:b1qq/dotfiles-sway.git ~/.dotfiles`
2. `cd ~/.dotfiles && ./install.sh`

## Что внутри
- `sway/` — конфиг Sway
- `i3status/` — конфиг статус-бара
- `rofi/` — темы и меню выключения (power-menu)
- `scripts/` — вспомогательные скрипты
